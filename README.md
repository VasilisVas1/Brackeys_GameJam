# Fever Dream

Fever Dream is a 3D adventure game developed in Unity using C# for **Brackeys Game Jam 2025.1**.  
The game follows a **lumberjack on his journey to his cave for a nap**, where unexpected challenges arise, aligning with the jam's theme, **"Nothing Can Go Wrong."**  

**Ranked #492 out of 2,200 submissions**  

## Gameplay

- Navigate through a **forest** as a lumberjack aiming to reach his **tent inside a cave**.  
- Encounter **unexpected obstacles** that test your problem-solving and navigation skills.  
- Immerse yourself in a **low-poly world** with atmospheric sound and visuals.  

## Features

**Immersive Forest Environment** – Explore a low-poly style nature setting.  
**Engaging Challenges** – Overcome obstacles that make the journey more interesting.  
**Thematic Storyline** – "Nothing Can Go Wrong" takes on a whole new meaning in this adventure.  

## Development

This project was developed **solo** within a week using **Unity and C#**.  
Here are some of the key assets used:  

- **Background Music** – [Background Music](https://www.youtube.com/watch?v=7_cwKd81z7Q)  
- **First Person Controller** – *Modular First Person Controller* by Jess Case (Unity Asset Store)  
- **Models** – *SimpleLowPolyNature* (Unity Asset Store)
